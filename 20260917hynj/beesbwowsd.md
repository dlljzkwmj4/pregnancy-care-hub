# 肩膀里面长石头，到底怎么回事？

> 更新时间：2026-09-17 (UTC+8)

近日，柳州市工人西院肩痛门诊来了一位患者，她向医生反映自己肩膀已经疼得三四天夜不能寐了，犹如刀割一样，这也不是第一次疼了，但没想到这一次这么严重。

经门诊详细检查后，才得知患者肩膀的肌腱里长了一大块超过三公分的“**石头**”，医学术语称之为**肩关节钙化性肌腱炎**。

**什么是肩关节钙化性肌腱炎，什么原因可导致？**
据运动医学肩肘外科副主任许鉴博士介绍，钙化性肌腱炎是肩关节的肩袖肌腱沉积钙化成份物质造成关节炎症反应及疼痛的疾患。此病发病原因未明，一般认为是细胞钙代谢出现异常导致。

**什么人容易发生钙化性肌腱炎？**
一般发生于40-50岁患者，多为上臂轻度体力劳动者，如家庭主妇、上班族、教师等，糖尿病的患者发病率较高。尤其是肩关节需要长期地内旋（比如手伸到背后解扣子）或者做稍微外展的动作（工人、收银员、办公室人员）的人员。

教师等长期外抬肩膀容易诱发钙化性肌腱炎发生

**钙化性肌腱炎有什么临床症状？**
1. 肩部持续性剧烈疼痛，夜间可痛醒；

2. 患肩绞锁感、无力、僵硬、手臂上举困难，关节活动度受限。

3. 肱骨大结节处压痛明显；

4. 低热、全身乏力。

**钙化性肌腱炎怎么治疗？**
许鉴博士说，许多钙化性肌腱炎可通过休息、消炎药物治疗、理疗、功能锻炼等保守治疗得到好转，症状严重的可通过局部注射类固醇药物进行治疗。若钙化灶比较硬且比较大，尤其是钙化灶已经侵蚀肌腱而非位于肌腱上，**经保守治疗仍无明显好转，可通过关节镜治疗痊愈，**仅需**两到三个****5mm**的小切口便可完全释放钙化灶并且修复损伤的肌腱，彻底解决疼痛。
