# 湖州首例！绒毛穿刺染色体检查

> 更新时间：2026-09-16 (UTC+8)

近日，湖州市妇幼保健院完成**全市首例绒毛穿刺染色体检查**，后续染色体检查结果显示胎儿为21-三体综合征（Downs综合征）。孕妇选择了引产处理，减少了孕中期羊水穿刺的等待时间，缓解了孕妇的焦虑。01

什么是绒毛穿刺？
绒毛穿刺是**最早期的介入下产前诊断染色体异常的方法**，一般绒毛穿刺的时间为**孕11~13+6周**，随着早孕期血清学和高分辨率超声筛查的逐步开展，绒毛活检技术也在逐渐普及，其最大的优点就是可以早期进行诊断，为后续的监测、干预及处理提供足够的时间。02

哪些人适合做绒毛穿刺？

1. 孕妇早期胎儿颈项透明层（nuchal translucency, NT）厚度≥ 3 mm；

2. 孕早期联合筛查高风险；

3. 由于家族中先证者（家族遗传性疾病调查中被诊断的第一个具有临床症状或表型的人）有单基因遗传病且夫妻为致病基因携带者而行产前诊断；

4. 孕妇年龄≥35 岁；

5. 既往分娩染色体异常胎儿；

6. 除 NT 增厚外， 存在其他超声异常。

03

哪些情况下不适合做绒毛穿刺？

1. 孕妇有流产征象者；

2. 孕妇有感染征象；

3. 孕妇凝血功能异常；

4. 双胎妊娠；

5. 不能完成绒毛活检或不能配合相关检测者。

04

绒毛穿刺有哪些风险？

**流产风险**：绒毛穿刺是一种侵入性操作，其流产的风险大约在0.5%~1%之间。**感染和出血**：由于穿刺过程中需穿透子宫壁，存在一定的感染和出血风险，但这种风险都可以通过严格的无菌操作和术后护理来降低风险。**其他并发症**：包括轻微的腹痛、阴道出血等，通常会在短时间内消失。
